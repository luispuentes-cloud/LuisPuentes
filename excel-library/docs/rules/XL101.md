# XL101 — estimated-section-count

**Severity:** WARN  
**Confidence:** HEURISTIC  
**Requires:** none

Blank-row gap analysis estimates more sections on a sheet than the budget
(default 5). The count is an estimate, not a declared block inventory.

**Remediation:** consolidate sections or document why the estimate is misleading.

**Fixture:** seven label-plus-data groups separated by blank rows.
