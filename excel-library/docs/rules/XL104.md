# XL104 — input-styling-not-redundant

**Severity:** WARN  
**Confidence:** HEURISTIC  
**Requires:** REF_GRAPH

A formula-dependent constant is missing distinct input styling. Number format
alone is not enough: both a non-default font and a fill are required.

**Remediation:** apply redundant input styling (font and fill) and provide an
on-sheet legend.
