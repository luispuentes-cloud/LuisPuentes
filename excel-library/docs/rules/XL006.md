# XL006 — inconsistent-period-axis

**Severity:** ERROR  
**Confidence:** HEURISTIC  
**Requires:** none

Where two or more sheets have the same detected period labels, they must start
in the same column. Where no period axis is detected at all, the rule emits
`INFO` rather than remaining silent.

**Remediation:** align matching period sequences to the same column index.

**Fixture:** `FY26 FY27 FY28` in `Calc!D:F` and `Summary!E:G`.
