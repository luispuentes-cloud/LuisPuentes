# XL001 — unlabelled-named-constant

**Severity:** ERROR  
**Confidence:** CERTAIN  
**Requires:** REF_GRAPH

A defined name pointing at a single numeric constant is referenced by a formula,
and the constant has no text label in the cell immediately left or above.

**Remediation:** add a text label immediately left of or above the named constant.

**Fixture:** `Inputs!C4` holds a named constant with the label cell blank; a
calculation formula references the name.
