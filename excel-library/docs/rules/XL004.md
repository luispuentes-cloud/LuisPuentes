# XL004 — text-in-numeric-cell

**Severity:** ERROR  
**Confidence:** CERTAIN  
**Requires:** CACHED_VALUES, NUMBER_FORMATS

The cached value is text and the cell's number format is numeric or currency.

**Remediation:** move status text to a status column and keep the numeric cell numeric.

**Fixture:** `E12` formatted `$#,##0` with cached text `N/A - no FTE load`.
