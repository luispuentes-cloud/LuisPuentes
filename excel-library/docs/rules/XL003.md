# XL003 — mixed-formula-shape-in-run

**Severity:** ERROR  
**Confidence:** HEURISTIC  
**Requires:** FORMULA_TOKENS

An inferred contiguous formula run contains more than one normalised shape.
The finding reports the run bounds it inferred.

**Remediation:** use one copied formula shape or separate the exceptional column.

**Fixture:** `D9:F9` copy one shape; `G9` is a trailing `SUM`.
