# XL005 — text-in-aggregated-range

**Severity:** ERROR  
**Confidence:** CERTAIN  
**Requires:** CACHED_VALUES, REF_GRAPH

A text cell sits inside a range that an aggregate function elsewhere sums.
This names the sum being silently broken.

**Remediation:** remove text from the aggregate range or use a separate status column.

**Fixture:** `Calc!E11` is text inside `SUM(Calc!E10:E11)`.
