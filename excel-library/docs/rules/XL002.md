# XL002 — numeric-literal-in-formula

**Severity:** ERROR  
**Confidence:** CERTAIN  
**Requires:** FORMULA_TOKENS

A formula contains a numeric literal that is not on the allowlist and is not in
a positional exemption (for example `ROUND`'s second argument).

**Remediation:** declare the value as a labelled input and reference it.

**Fixture:** `Calc!D7` contains `=C7*0.85`; `ROUND(..., 2)` must not fire.
